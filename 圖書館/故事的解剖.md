# 故事的解剖

> 狀態：已讀
> 閱讀日期：

![[covers/故事的解剖.jpg]]

# 心得與簡述

對於我而言，故事是什麼？故事可以是乘載著某種價值觀的媒介，可以是將觀測的事實包裝後的產物，可以是某個人心中的風景的具現化。作為加工後的產品，易吸收，好理解，具備趣味性，便是我對故事的要求，也是我所認同的故事。珂朵莉一生在追尋的幸福本質的命題；章魚次郎問為什麼自己是章魚的詰問；阿爾吉儂對於自己的悼憐，以上的共通點為主軸性強，收束感強烈，我熱愛這類型的故事。那麼，為什麼是這些？歷史劇不行嗎？青春戀愛的主題不好嗎？紀錄片哪裡入不了法眼了？一直以來，我都有這疑問，但疑問多半停留於此，因為我無法再將問題拆解得更細，只能止步於此。這可以是理由，對我來說卻遠遠不夠。為什麼？因為我知道，這並非我想過的生活。我喜歡拆解事物所帶來的透明感，看著手中的一切，在掌心裡逐漸明朗，是一件令人雀躍的事情。今日有幸碰到這本書，令我大開眼界。作者將「故事」這框架拆解細分到無孔不入的狀態。一本結構性極強，且切合「[[如何閱讀一本書]]」的方式，適合作為主題閱讀的一本書。因此我將以本書為主題，對故事本質的體悟盡情傾訴，不敢說吸收進作者的所有知識，但我會竭盡所能的，解釋我喜歡故事的緣由與經緯。
在主題分析的框架中，我將書籍內容做出三部分的分析，分為關鍵字、大綱與論述。關鍵字提取本書的最精華重點，方便理解全文的要旨。大綱旨在將全文拆解成細項，方便解構並理解內文。最後論述的目的，則在於將既有知識轉變為自己語言，重新輸出我對本書的看法，這同時也是難度最高的一環。而此篇心得就依順序進行。首先將關鍵字闡明，提供大綱的脈絡，最後在實務問題回答以下幾個問題我曾經有過的疑惑：
1. 說明故事與散文的差異性。
2. 故事為什麼不能全部都要。
3. 寫作時為何需要帶入角色與影響。
4. 閱讀此書前後的故事體驗差異。
5. 為何會有推理十誡或創作守則的出現。
這些論證會在後文一一介紹。而在此之前，我應該從本書的伊始，關鍵字開始說起。

# 關鍵字

**目的**我認為是本書的關鍵字。儘管這字根很少出現，但我仍認為是貫徹全書的靈魂。
目的＝想讓誰在讀完之後『理解/感受/行動』什麼。故事是將你的所思所想透過一連串事件編排後產生的產物。編排順序不必符合時間、事件因果。事件的真相可以被任意拉伸延長，最終形塑的產物只要能服務於特定受眾，我就會定義他為故事。
想寫好一個故事，你得先決定你的受眾是誰，你想在這故事裡達成什麼**目的**。證明人性本善？復仇無果？神探破案？自我救贖？這些都可以。不斷清晰我們要闡述的觀點。縮編故事視角，決定幕的切換，編排場景，安排角色入戲，設計對白。這一系列動作須由上到下去雕塑**。**方能貫徹目的。
然而，理論上的理想與實務上的現實常有落差。實務上常會遇到我是為了創造某個場景或角色，而安排了這個故事。我們向角色妥協了故事框架，向場景妥協了鋪陳。看似愚蠢，顛覆因果，只為了描繪出心中的理想風景。因此我們不斷在創作並推翻著自己的框架。角色設計？那連序言都說不上，得推斷出角色的核心宗旨，再以特定的目的編寫出結果，方能完成故事。實務上，自傳便是最常碰到倒果為因的類型。自傳是根據事實加以改編的，但若大家真想看編年史，為何不直接看史書就好了？故事的內容，都需要須將**某件事的真實**審視後包裝，從真實抽絲剝繭找出意義，這是每個故事都會遇到的難題。
也因此，我認為要寫好一個故事，最重要的便是目的。同時本書的宗旨，**故事的解剖**其核心論述，便是教導你如何將目的從字裡行間抒發，從角色性格滲透，在背景下演繹，進而轉化為一個有血有肉，條理分明的故事。

# 大綱

以框架而言，本書可分為做什麼樣的故事、故事的組成成分、以及寫故事會遇到的實務問題三大類。我會延續這個脈絡將框架再細分。且本讀書心得目的是為了汲取創作故事的概念，若是專門寫給電影的補充我會跳過。
一開始「做什麼樣的故事」講解故事的分類方法。一個劇本完成後，我們能將劇情分類為原型、極簡、反劇情三種。這並非一個絕對的分類，若將三種類至於三角形的端點，其邊上可以容納各光譜的劇情。
原型故事屬於封閉的線性故事，主角主動或被動受到外力影響改變了自己本來的生活。操作手法最為簡單，以線性的方式事件前後因果、主角心境、動機、思考模式鋪灑在其中。而置入的核心價值觀、衝突往往就能在核心的事件一覽無遺。簡單好操作、觀眾易理解，便是原型故事。
極簡故事置於端點的另一端。隱密、克制、留白，是極簡故事的核心宗旨。若將原型故事比喻為加法，將故事這媒介從零打造至一；那極簡故事便是減法，將一塊故事的基石，用最少筆畫去打磨，卻擁有最完整的框架。題材方面，受限於寫作方式，景物、動作描寫並不會是其強項。內心掙扎、心情波瀾則是其長處。比起原型故事，極簡故事更注重在內在的變化。
反劇情與其說是一種分類風格，更像是跳脫劇本的出色案例。而這與亂寫有什麼區別呢？差別在作者完全知悉劇本的運作，並有意地去扭曲套路。這種劇本的鑑賞門檻高，是在大量閱讀作品後，逐步建立對套路的認知後，才會理解「反劇情」的出色。能欣賞反劇本的人，必然是對「套路」是有概念的，正因為熟悉，才能品鑑作者跳脫套路時的花樣。
雖然極簡、反劇情看似是更高竿的藝術。然而類型並無優劣之分，只有喜好之別。原型故事之所以會是主流。是因為人類回憶記憶的方式，便是透過線性來回溯，通俗與低鑑賞門檻便是其特色。另外兩種類型的衍生，我認為是出自對審美的偏好演變而來的。就個人角度我也最喜歡原型故事，依類型排名由上到下，分別是原型＞反劇情（原型）＞極簡＞反劇情（極簡）。極簡風格受限於我神經比較大條，留白我不一定能看明白，更遑論極簡的反劇情。
若描寫得越內斂，對我來說越是苦手。從前我是認為我喜歡留白故事的，但真的對照範本後，我發現深度與價值衝突才是我更喜歡的東西。透過這劇本分類，它便徹底推翻我之前的看法。
而後來到故事的組成。作者將組成分為幕、序列、場景、段落、對白……等數個層面。我是這樣理解的。由左到右是故事由大到小差分而成的產物。越到右側，要完成的項目也越少。目標也會逐漸的具體化，清晰化。好比說幕要達成影響故事走向的重視事件，但具體要達成什麼事件、怎麼算完成，都因劇本而異。然而細分到對白時，這任務就會簡單很多，舉例來說：這段對白要表達出主角因無法完成願望而抱怨了一番，凸顯主角有碎碎念的習慣。越是底層越是基本，越好被執行。當階段性任務要完成後，將角色轉往不可逆的階段邁進。同時這些構成故事的節點們，都會隨著故事的進展逐漸加大節點的力度，將這一步步的對白堆砌起來，越堆越高，越使讀者沉浸，在終局來臨時，拼湊出故事這個載體。
這些分類的詳細用途，並非我的探討目標。分類到這麼細緻的目的，推測是方便控管進度而規定的框架。我認為隨著熟練度的提升，會自然而然達成每個項目待達到的條件。至於是否要照著框架走呢？可以不遵守，但框架的目的就是方便人們控管故事。因此我認為，與其羅列這些項目的定義，倒不如直接嘗試模組化我的故事。我認為會是最好的練習，因此這邊會延伸到我的練習成果，希望能藉此更理解分類的根本用意。

# 實務問題：論述

最後是寫作會用到的實務問題，這些問題是我過往無法回答的。透過這本書的故事框架與故事分場概念，去嘗試去解讀當中的意涵。
說明故事與散文的差異性：
故事價值在於提供變化，存在某個瞬間的不可逆。這當中由幕去承擔著這樣的職責，透過幕與幕之間，將故事銜接起來。而我對散文的看法，專指**以抒情與片段性為主、弧線非核心驅動**的寫法。是某個場景的心境延伸，延伸的長度取決於作者的意願，延伸的越長，劇情流動感越弱。縱使劇情是有連貫的，但幕與幕之間的連動、映射不會像故事那樣明顯，散文更多是透過文字，以心境勾勒場景內的輪廓描寫。
故事為什麼不能全部都要：
一千個哈姆雷特就有一千種寫法。確認目的後其實就已經釘死了自己能寫的範圍。先不論手法高低，在我決定主軸是溫馨的故事後，手法裡面自然比較難出現冰冷的文字。反之亦然，萬宗不離其心。得知道自己要什麼，寫什麼的時候才有辦法控管自己想表達什麼。什麼都想要，可以。那你得準備足夠的篇幅與充足的鋪陳。那這是否又會違背你定義的故事長度，且繁複與多樣的價值並列，極有可能會使劇情失焦。什麼都要，那也代表你什麼也不要。在有限的篇幅裡，講述一個或兩個核心觀點會是比較能凸顯故事主軸的方法。
寫作時為何需要帶入角色與影響：
為了故事完整度而創作角色，這是必須且合理的行為。但角色如何避免淪於龍套，或成為故事的背景說明版，就須帶到為什麼要懂角色在想什麼？為的是讓你更清楚角色是為了什麼而出現，進而推估這角色會如何變動故事。掛在牆上的槍就必須擊發，角色若設計只是為了推進故事劇情而出現的，對觀眾會產生一個疑惑，那麼如果不是這個人？不是這個人出現在這裡，透過其他人推動劇情又會是什麼樣的故事，符合了故事，卻從未滿足過觀眾的回應。出色的設計會讓每個角色都擁有核心宗旨，宗旨不該為了故事而存在，而是為了自己存在。他的其目標/價值一致且可預測，**因此當他做出選擇時，情節的推動即是其性格的外化**。否則在敏銳的觀眾看來，這種角色的出現只是為了推進劇情而產生的機械降神，屬於意料之中，情理之外。看久了會膩。
閱讀此書前後的故事體驗差異。
閱讀後彷彿開了新的大腦。出現了不同思維的聲音。開始理解劇本的背景故事的必要性。以及探索過場的合理性。背景與過場是為了讓我們有正確的故事認知。為了定調故事基石，而存在大量設定的序章不再被我嫌棄。但現在回過頭來看，這種場景鋪陳是為了建立我對故事的正確認知。我不再感到無趣，更能沉浸在故事中，並多了種新的樂趣，能具體挑出前文鋪陳不足而造成的段落突兀感。又好比說，面對故事擴寫時常出現的思緒發散。過往我是說不出原因的，只能用這段開始「無聊」了概誇。現在也能指出是因為主線暫時失焦，而副線承擔的線路不夠沉浸。這些便是我具體能在這本書裡指出的細節，也是我過往一直想努力，卻也沒能達成的目標。
為何會有推理十誡或創作守則的出現：
這是為了符合創作邏輯。我們能接受現實裡面出現的荒謬，是因為現實就是這麼鬼扯。但故事不同，故事講求的是蘊含在規則下的合理變化。情理之中，意料之外是故事最想看到的走向。守則是在維護情理之中的界線，當超出某個界線後，故事會從情理之中變為情理之外。觀眾不再認為故事講道理，而是天花亂墜的胡言亂語，這時我寧可去看現實的荒謬，我也不想承認故事的荒腔走板。當然，守則會隨著時代的變化，觀眾的適應度微調，然而每個時代的守則，都是為了守護這吋框架，而有的硬限制。

# 作品論證

> 作品有說服我嗎？
有的。這作品給我一個嶄新的思維。過往理解故事需要建立畫像與人物側寫，我隨意地捏造角色與設計對白，使故事充斥著大量無用資訊，當時認為這可以有效地拓展世界觀就使勁地寫進去，是種加法思維。但觀看本書後，我理解故事應是減法。將一個完整框架寫完後，刪除不必要且無法表達核心思想的觀點，將故事內容與角色性格串接起來。當中或有不捨，但只要違背了核心思想，不論這構想多麼誘人，都不應該放入，這對創作來說是很大的突破。
> 我喜歡嗎？
很喜歡，我喜歡介紹我感興趣的框架故事，這本便是其一。另外兩本同作者的書籍有機會我也會去觀看。
> 會推薦給別人嗎？
這本書偏硬，除非他真的喜歡創作故事啦。不然沒必要講這些五四三，很多時候喜歡就是喜歡，也沒必要糾結這麼多。
