## 三、資產概況

**持倉快照：2026/10/13（參考價 10/12）**

| 項目              | 數值                                 |
| --------------- | ---------------------------------- |
| 投資總資產           | **4,627,497** NTD                  |
| ─ 信貸餘額（2.8%）    | 1,219,755                          |
| ─ 股票質押本金（3.8%）  | 577,000                            |
| **真正自有淨資產 NAV** | **2,830,742** NTD                  |
| 組合外現金預備金        | **無**（2026/10 起不再保留）              |
| 月投入股市           | **105,000**（家庭 100,000 + 自有 5,000） |
| 月信貸還款           | 19,685（投資帳戶外現金流支付，不佔用上列 105,000）   |

> [!note] 兩種「投資現金流」不要混淆
> - **月投入股市 105,000**：增加投資總資產
> - **月信貸還款 19,685**：減少負債 → 增加 NAV，但不增加投資總資產
>
> 兩者都在累積淨資產，但走不同的科目，不應相加。

> [!warning] 流動性緩衝全部在 00865B，沒有組合外現金
> 原 40 萬現金預備金已不存在，**00865B 公債（約 83.5 萬）是唯一的流動性來源**。
>
> 失業情境試算：必要現金流出 ＝ 生活支出 24,650 ＋ 信貸還款 19,685 ＝ **44,335／月**
> → 83.5 萬 ÷ 44,335 ≈ **可支撐約 18.8 個月**（不計投入股市的 105,000，該筆應立即停止）
>
> 結論：緩衝仍然充足，但**公債部位不可低於配置下限 15%**，否則同時失去再平衡彈藥與生活緩衝。
