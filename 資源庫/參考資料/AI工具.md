## N8N

自動化工作流平台，用於串接各種 API 與服務。

### 建置步驟

1. 搞定 Docker，取得帳號密碼
2. 取得 Ngrok 網域
3. 取得 Google、LINE、Lark 的 API 權限
4. 設定工作流

### 參考資源

- [n8n + MCP Workflow 介紹](https://muki.tw/n8n-mcp-workflow-introduce/)
