## 觸發時機

- 使用者說「把這個存到 Obsidian」
- LINE/Discord bot 傳入需要儲存的內容
- 使用者分享文章、影片、想法需要整理

---

## 判斷存放位置

| 內容類型 | 存放位置 |
|----------|----------|
| 快速想法、碎碎念、靈感 | `靈感筆記/` |
| 書籍筆記 | `圖書館/書名.md` |
| AI 工具、技術參考、外部資源 | `資源庫/參考資料/` |
| 經過消化的核心知識 | `永久筆記/主題/` |
| 今日工作記錄 | `Daily Notes/YYYY-MM-DD.md` |
| 小說靈感、草稿 | `創作小說/小說靈感/` |
| 料理食譜 | `食譜/` |
| 技術專案相關 | `Projects/專案名稱/` |
| 個人抒發 | `日記/`（Claude 不寫入） |
| 圖片、附件、媒體檔案 | `Assets/` |

---

## 存入格式

```markdown
# 標題

來源：（URL 或來源說明）
日期：YYYY-MM-DD
標籤：#類別

## 重點摘要

## 原始內容 / 筆記

## 我的想法
```

---

## 判斷原則

- 還沒整理好的想法 → `靈感筆記/`
- 已消化、用自己的話寫出來的知識 → `永久筆記/`
- 外部工具、技術文件、影片筆記 → `資源庫/`
- 不確定的先放 `靈感筆記/`，之後再分類
