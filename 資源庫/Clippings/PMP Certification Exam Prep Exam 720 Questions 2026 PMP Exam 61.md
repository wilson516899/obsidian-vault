Question 34:問題34：

Facing an upcoming corporate audit that includes the agile project they are managing, the project manager is tasked with representing the project at the initial meeting with auditors.  
面對即將到來的企業稽核，其中包含他們所管理的敏捷專案，專案經理被指派代表專案出席與稽核師的初次會議。

How should the project manager prepare for this audit?  
專案經理應該如何準備這次稽核？

Your answer is incorrect 你的回答不正確

Allocate additional resources in the upcoming sprint for potential audit-related tasks  
在即將到來的衝刺中，為潛在的審計相關任務分配額外資源

Correct answer 正確答案

Thoroughly review all project documentation and progress to date  
徹底審查所有專案文件及迄今進度

Coordinate with the development team to compile relevant compliance documentation  
與開發團隊協調，彙整相關的合規文件

Seek an exemption from the audit for the project  
申請專案審核豁免
