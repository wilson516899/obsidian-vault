Question 152:問題 152：

Which of the following is an XP practice that helps to create a shared vision between the developers and the customers?  
以下哪一項是幫助開發者和客戶之間達成共同願景的實踐方法？

Your answer is incorrect 您的回答不正確。

Continuous integration 持續集成

Correct answer 正確答案

User stories

Pair programming 配對編程

Test-driven development

User stories are short, simple descriptions of features or functionality written from the user's perspective, typically following the format "As a \[user type\], I want \[goal\] so that \[benefit\]." User stories help create shared vision by capturing requirements in language both customers and developers understand, focusing on user needs rather than technical specifications, facilitating conversations between customers and developers about what should be built, and keeping the customer's perspective central to development decisions. User stories are typically written on index cards and serve as placeholders for conversations, ensuring developers build what customers actually need.

**Why the other options are not correct:**

Continuous integration is the practice of frequently integrating code changes and running automated tests to catch integration problems early, which is a technical practice that doesn't directly create shared vision with customers.

Pair programming involves two developers working together at one workstation, improving code quality and knowledge sharing within the development team but not specifically creating shared vision with customers.

Test-driven development writes tests before code to drive design and ensure quality, which is a technical development practice that doesn't directly involve customers or create shared understanding of user needs.
