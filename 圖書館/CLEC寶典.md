# 大綱

CLEC寶典是我近期閱讀後發大有收穫的一本書。本書幫助我理解了幾個關鍵資訊。

1. 買、借、死
2. 生命週期投資法
3. 質押系統
4. 槓桿與風險
5. 實作做法

我會以文字寫下我當前對此事的理解。
1.  買、借、死的本質是，貸款利率低於經濟成長速度的狀況下，在適當舉債併購買資產的情況下，可以加速財富增加的速度。這件事之前就已經透過信用貸款的方式，理解了這件事的運作邏輯。是透過換種見解，理解到這件事可行。
2. 不算是新觀念，本質是以時間維度去衡量投資的金錢。因為年輕時所賺的本金較少，對於風險的承受、耐受度會比年老時更高。因此應該在前期能承受風險時，適當的加大自己的槓桿程度。
3. 質押對我來說是新的投資理財工具，之前並不了解。這系統破除了我之前對股票漲多之後要不要賣的問題。股票增長的資產，可以一定比例的程度(2~4%)取出，理論上可以達到財富增長的目的，同時抵免自己日常的所需與花費。
4. 本書也理解了正二的本質與風險。過往對正二會所謂的波動性耗損問題與下跌過大的風險，無法願意持有。但透過本書，理解了何謂總曝顯這個概念。透過保留適當債券的部分，降低總曝險，就可以在自己的資產內部也配置相對應的正二資產。這樣的目的，是可以擁有大盤的總曝顯，卻又保留保留金錢這個部位。
5. 當前作法會以4:4:2的方式進行財富積累。具體標的會是00662、00631L、00865B。分別代表那斯達克100、台股指數正2、美國短天期國債。目的是120%曝顯，且近五年台股上漲潛能評估大於美股，所做的調整。當大盤下跌時，後續會考慮解債加股，但可能會是以下跌10%，加碼5%的美債為思路。總下跌40%時，全數加碼20%美股國債



# 作者論證

> 作者有說服我嗎？
> 這是一套嶄新的系統。他有透過一層層的觀念，去影響我思考。並觸發我對新的工具，質押的理解。我覺得有說服我，且願意讓我嘗試，這是一個很棒的書籍。

> 如何改變我？
我會嘗試使用他的投資方法，並按照他的行動方式去操作股票。我想試試看在這樣的狀況下，是否資金能如期成長。

> 我喜歡嗎？
還算喜歡，我喜歡吸收新知識的感覺。且這個知識並沒有強硬的需要我使用。而是客觀地提出一種想法與思考迴路，這種作法更符合我的需求。

> 會推薦給別人嗎？
會，但要是他願意去理解財經的人，不一定每個人都適用。這本書的目的在於啟發財商，在台灣財商普遍低下的狀況。如果推薦了三人有一人願意閱讀，那就是件好事。
