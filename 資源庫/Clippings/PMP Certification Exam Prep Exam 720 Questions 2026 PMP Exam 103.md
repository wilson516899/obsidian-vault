Question 108:問題108：

For an upcoming large-scale software implementation project, the project manager finds out that obtaining certain proprietary software licenses will significantly delay project kickoff due to the vendor's extensive verification process.  
對於即將到來的大型軟體實作專案，專案經理發現取得某些專有軟體授權會因供應商繁複的驗證流程而大幅延遲專案啟動。

What should the project manager do to mitigate this delay?  
專案經理應該如何減少這種延誤？

Your answer is incorrect 你的回答不正確

Propose a phased project kickoff, starting with components that do not require the proprietary software  
建議分階段啟動專案，從不需要專有軟體的元件開始

Seek temporary licensing agreements that allow the project to commence while awaiting full verification  
尋求臨時授權協議，允許專案在等待完整驗證期間啟動

Escalate the issue to executive management to leverage higher-level contacts with the software vendor  
將問題升級至高層管理，利用與軟體供應商的高層聯繫

Correct answer 正確答案

Collaborate with the procurement department to identify strategies for accelerating the licensing process  
與採購部門合作，找出加速授權流程的策略
