Question 27:

A project manager has completed cost estimating for all project activities and work packages. The estimates include labor, materials, equipment, and other direct costs. The project sponsor is now asking for a comprehensive budget that can be used to measure cost performance throughout the project lifecycle.  
項目經理已完成所有項目活動和工作包的成本估算。這些估算包括人工、材料、設備以及其他直接成本。項目發起人現在要求一份全面的預算，以便在整個項目生命週期內衡量成本表現。

What should the project manager do next?  
項目經理接下來應該怎麼做？

Submit the cost estimates to the sponsor as the project budget  
將成本估算提交給贊助方，作為項目預算的一部分。

Add management reserve to the estimates to create the final budget  
在估算中增加管理預留資金，以確定最終預算

Your answer is incorrect 您的回答不正確。

Distribute the cost estimates across the project timeline to show when funds are needed  
將成本估算分散到整個項目的時間線上，以便清楚地顯示資金需求的時間點。

Correct answer 正確答案

Aggregate the cost estimates and add contingency reserves to establish the cost baseline  
彙總各項成本估算，並預留應急備用金，以確定實際成本。
