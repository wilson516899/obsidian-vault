Question 68:問題 68：

A project manager is leading an agile software development project when the product owner wants to add several new features that weren't in the original product vision. The development team has capacity to take on additional work, and the new features would provide significant customer value.  
項目經理正在領導一個敏捷的軟件開發項目，而產品負責人希望添加一些新的功能，這些功能在最初的產品願景中並未包含。 開發團隊有能力承擔額外的任務，並且這些新功能將為客戶帶來顯著的價值。

How should scope changes be handled in an agile project?  
在敏捷項目中，如何處理範圍變更？

Your answer is incorrect 您的回答不正確。

Submit the new features through formal change control for approval before adding them  
在正式變更控制流程中，先獲得批准後，再將新功能添加到系統中。

Reject the changes since they weren't part of the original project scope  
拒絕這些修改，因為它們不屬於原始項目的範圍。

Correct answer 正確答案

Add the features to the product backlog for prioritization by the product owner  
將這些功能添加到產品待辦事項列表，以便產品負責人進行優先級排序。

Create a change request and update the scope baseline before proceeding  
創建變更請求，並在繼續之前，更新基準範圍。
