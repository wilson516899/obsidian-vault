Question 83:問題83：

A project manager in a software development project is implementing an Agile methodology. The team has faced multiple iterations where the deliverables did not meet the client's quality expectations, leading to dissatisfaction.  
軟體開發專案中的專案經理正在實施敏捷方法論。團隊曾多次遇到交付成果未達客戶品質期望，導致不滿的情況。

What action should the project manager take to improve the deliverables' quality in future sprints?  
專案經理應該採取什麼行動來提升未來衝刺階段交付物的品質？

Correct answer 正確答案

Introduce peer reviews and pair programming practices to enhance code quality before client reviews  
引入同儕審查與配對程式設計，以提升程式碼品質，然後再進行客戶審查

Implement automated testing for continuous integration to ensure that bugs are caught and fixed promptly  
實施自動化測試以進行持續整合，確保錯誤能被及時發現並修正

Conduct a comprehensive training session on Agile and quality best practices for the development team  
為開發團隊舉辦全面的敏捷與品質最佳實務培訓課程

Your answer is incorrect 你的回答不正確

Reevaluate and refine the definition of "done" with the team to ensure it includes rigorous quality criteria  
與團隊重新評估並精煉「完成」的定義，確保其中包含嚴格的品質標準
