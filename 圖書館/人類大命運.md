# 大綱

先訴說動物與人類的差別（在人類大歷史）。接著提到人類稱霸了地球。我們是透過什麼魔法，突破了讓陌生人彼此合作的核心（宗教、意義。）
我們透過賦予這兩者意義，讓人類能凝聚彼此意識。這件事中古時期可行，但在近代時被科學革命打發。人們開始高呼自己的權利，人文意識開始高漲。在現代，人文主義又因其侷限性，分裂為社會人文（左派、共產），進化人文（右派、納粹）。
二十一世紀初，看起來，原始人文主義復出，兼容一些社會人文、與進化人文，再度稱霸全球。現在，出現了新時代的挑戰，名為數據科技的人文主義出現，人們是否會將自己的意識，轉給數據呢？以此作結。

# 果實是什麼

意義：人類編織出最大的謊，為了讓人能活下去。人需要謊言，需要意義。
過往的相關理論已經坍塌。現在最著名的幾個理論。

互為主體性：雙方彼此主觀認定此觀點，界定一種狀況，符合彼此的認知。
幾乎沒人在意真相。表格上寫的，才更重要。

宗教神授主義：神是偉大的，所有榮耀皆歸于上帝。財產、資產有限，不相信成長。
資本主義：成長、再成長。相信餅是可以越畫越大的。
人文主義：為無意義的世界創造意義。人才是這世界上的主宰。盲區：自由主義盲區：我當下的政治觀點、喜好厭惡、興趣與抱負，可能不是反映真實的自我，只是反映出我的成長和社會環境。

宗教掌控秩序、靈性是趟旅程、科學冀求力量
宗教與科學是可以攜手合作的，靈性則比較難。

# 葉脈是什麼

### 人類對動物做的事情

人類定義了智人的至高無上性。主張擁有自我意識，因此能統治世界。
信仰由多神轉為一神時，貶低了非人的事物。和諧共存的方式不再。人進貢特定商品以滿足神的考驗。動物由動物轉為商品，不再平等。

### 人類憑藉自我發展的文明

認知發展、農業發展、大航海時代發展、科學革命
大航海時代開始，人認定自己無知的那刻起，知識開始向外拓展，視為科學發展的先驅，不再視神為唯一解方。資本主義開始發展，神本位趨向人本位。人本主義興起，後期演化分為社會人文、自由人文、進化人文。
多樣化的文明，皆是以人為本位的文明，但挑戰開始出現。現代科技「演算法」出世，或許新的世代已經到來。

### 自我並非不可分割的最小單位

生物學家早已認定，無所謂的靈魂。現時點，自我也被確認為一堆賀爾蒙、基因的作祟。既然自我並非唯一的代表，那麼，人本主義的一大要素，唯一獨特這論點也不攻而破。

### 演算法的出現

那麼，沒有自我的高知識密度模塊，是不是可以取代自我呢？這就是演算法。這是現今人類遇到的問題，他比你聰明，比你還熟悉你自己，那麼自我把控還有意義嗎？為什麼不能把主動權交給演算法呢？
工作會被取代，人實在太多了。不需要這麼多人，大量的人會從被剝削、變成無足輕重。若是活得如此荒謬，如此無知。或許維持一個機器比維持一個人要緊的時刻，就快到來了。

### 那麼，演算法是否能取代自我

我並非抱持如此不樂觀的看法。觀點如下：
1.人口成長趨緩，培育教育趨重質。人們已意識到這點，人真的太多了，自殺率、內捲，這些東西都是修正人口的最佳典範。政府是阻止不了的，再多的福利政策，在人口回歸土地最適居住空間時，都不會停止。
2.小孩的適應性，看看我爸媽。對於電腦的不適應性，就如同我現在對於GPT的不適應性，可以學習，但學習成本、曲線不如更幼者，他們會做得比我們更好，我們都活在變革的年代，管理大師明茲柏格如是說，但每個世代，都會有出類拔萃的人，他們依照他們的意思掌控了社會，但總體會朝向一個好的方向發展。或許並非我們想要。只是附加結果改善。但於此之上，我就不擔心人類會被機器取代。當然，若是不想被這陣風拋下，那麼，比起機器更了解自己，就是另一個基本功了。
3.意識的網。我們活在多層謊言構築下的社會。你想要選擇哪個網，是你自己決定。今天就算演算法已經確定了，你過著他的路線走會比較快樂，但決定權是在你。那時候，問問你自己吧，你想聽他的，還是走著你的陽關道？？
