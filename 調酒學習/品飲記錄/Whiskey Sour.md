# Whiskey Sour 威士忌酸

## 個人筆記

有檸檬清香，但威士忌的調性被檸檬搶走，後勁不強。  
可持續入口，少了嗆辣感。整體偏輕，找不到威士忌的個性。

> 基於此杯原料，推薦尚未嘗試、但有直接關聯的調酒。

**換甜味來源 → 改變甜感質地**
- **Gold Rush**（Bourbon + 蜂蜜糖漿 + 檸檬汁）— 把 Simple Syrup 換成蜂蜜，甜感更圓潤有深度，威士忌個性也更容易被感受到（Claude推薦）
- **Bee's Knees**（Gin + 蜂蜜糖漿 + 檸檬）— 同樣換蜂蜜為甜味來源但基酒改成琴酒，比較蜂蜜甜感搭配不同基酒的表現（Claude推薦）

**加一層 → 相同結構增加維度**
- **New York Sour**（Whiskey Sour + 紅酒 float）— 在你喝的這杯上面加一層紅酒，入口酸甜、尾韻帶單寧，視覺也好看（Claude推薦）

**換基酒 → 同 Sour 結構，感受不同烈酒**
- **Amaretto Sour**（Amaretto 杏仁利口酒 + 檸檬 + 蛋白）— 同 Sour 結構但基酒換成堅果甜酒，甜度高、苦感低，跟你的偏好反向，有助定位（Claude推薦）
