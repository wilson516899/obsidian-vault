## 🔄 調整（7/1）

### Daily Note 路徑改為月份子資料夾結構

**改了什麼：**
- `notify.py`：寫入路徑從 `Daily Note/{TODAY}.md` 改為 `Daily Note/{YYYY-MM}/{TODAY}.md`
- `notify.py`：`collect_context()` 讀取過去 7 天的路徑同步加入月份子資料夾
- `notify.py`：`update_homepage()` regex 相容新舊格式（有無月份子資料夾的 wikilink 都能 match），統一更新為新格式 `[[Daily Note/YYYY-MM/YYYY-MM-DD|今天的 Daily Note]]`
- `quest.py`：讀取昨日路徑從 `Daily Note/{YESTERDAY}.md` 改為 `Daily Note/{YESTERDAY[:7]}/{YESTERDAY}.md`
- `month_archive.py`：讀取上月每日檔路徑改為 `Daily Note/{MONTH_STR}/{date_str}.md`（原從根目錄讀）；移除移檔步驟（`shutil` import 一併移除）
- 補移已存在的六月日報（06-01 ～ 06-30）至 `Daily Note/2026-06/`，以及七月 07-01 至 `Daily Note/2026-07/`

**推論：**
原本腳本一直把日報寫在 `Daily Note/` 根目錄，但月份彙整用的子資料夾（`2026-05/`、`2026-06/`）早已存在——這是 month_archive.py 在月底把檔案「移入」子資料夾的設計。問題在於：若 WSL 停機導致 month_archive.py 沒跑，整個月的日報就永遠堆在根目錄；而 month_archive.py 也必須在月底前才有機會整理。
改為「寫入時就直接放進月份子資料夾」，讓路徑從一開始就是正確的，month_archive.py 只需負責產彙整，不再需要移檔，消除了這個月底的隱性依賴。

### month_archive.py 新增應有次數欄位

**改了什麼：**
- 新增 `get_expected_counts(year, month)`：計算該月各任務類型的應有次數（固定日 = 月天數、運動日 = 週二+週四天數、一般日 = 週一三五天數、週任務 = 月內 ISO 週數）
- 新增 `classify_task(name)`：以關鍵字比對判斷任務類別（找團/揪人/說出 → 週任務；運動課/PMP30 → 運動日；PMP45/飯後走路 → 一般日；寫作 → 不定；其餘 → 固定）
- `build_report()` 任務表格新增「應有次數」欄位
- README 輸出格式說明同步更新；skills-index daily-notify 說明補入月份彙整功能描述

**推論：**
原本月份彙整只有完成次數，看到「寫日記 2 次」並不知道這是 2/30 還是 2/5，沒有參照點就無從判斷執行率。加入應有次數讓這個數字變得有意義，也讓月底回顧時能快速找出哪類任務最常被跳過。

## 🔄 理財專區大重構（7/4–7/6）

### 四分法重構：一份文件只裝一種性質

**改了什麼：**
- 確立四種性質、各自獨立：`理財系統`（全局收支+資產）、`消費決策系統`（消費方法論）、`投資研究`（投資）、`記帳/`（實際數據）
- 新建 `理財/理財系統.md`：收入結構、每月預算（依 LightByte 截圖）、資產概況、財務里程碑
- 消除重複：月收支原本同時存在理財系統與投資研究，統一到理財系統；投資研究只留投資內容
- `印尼記帳.md` 移入 `記帳/`，讓「記帳」只有一個入口
- 同步更新理財總覽、CLAUDE.md

**推論：**
理財內容原本散落、且月收支在兩份文件各記一套（數字還不一致）。用「一份文件只回答一個問題」切乾淨，避免 drift。

### 消費決策系統擴充

**改了什麼：**
- 新增「個人消費優惠地圖」（固定支出 / 高頻 / 大額三層對應支付方式）
- 新增「台新 Richart 權益明細」（六種權益、每日可切、已知 Pay著刷 3.3–3.8%，其餘待補）
- 航空里程從理財系統移到此（定位為省錢環節，非全局項目）
- AwardWallet 標為 B 級待辦（三個啟用條件，暫不管）
- 7-11/全家 加 LINE Pay

### 投資研究大改：確立完整投資策略

**改了什麼：**
- **Dynamic LTV v1.0**：質押定位為「熊市才動的資本工具」，LTV 為唯一指標，常駐 10%、上限 30%，依組合回撤（High Water Mark）加碼
- **融入出場風險理論（槓桿人生 #36）**：三種槓桿失敗方式（信貸=現金流、正2=心理出場、質押=制度出場）
- **目標配置定案（barbell）**：那指 00662 30% / 那指正2 00670L 20% / 費半含台積 20% / BRK 30%；有效曝險 ~120%
- **持倉解碼**：券商說台股 65%，實際美股曝險 ~97%（00830/00662 追蹤美指）
- **建倉計畫**：全程不砍倉，純月流 DCA 建 00670L、超重部位靠稀釋降比例
- **下跌應對 SOP**：回撤分層動用火力（月流→現金→質押）
- 標的研究統一格式「台股代號（美股標的）」；刪除待研究方向
- 定期定額金額確認為 10,000/月

**推論：**
Wilson 有 285 萬持倉、每月 11 萬（含家庭資金）現金流、40 萬保命底。目標是把過度集中的半導體（35.7%）調成 barbell（正2 進攻 + BRK 防守），並用「只買不賣、月流補低」的動態補倉紀律執行，避免情緒與稅務摩擦。質押作為深熊最後一層，但受限於「BRK 複委託不能押、可押的都是高波動品」，須保守。

### 理財總覽併入理財系統（7/6）

**改了什麼：**
- 刪除 `理財總覽.md`，導覽（連結 + 分區原則）併入 `理財系統.md` 最上方
- `理財系統` 成為理財專區唯一入口（上半導覽、下半財務數據）
