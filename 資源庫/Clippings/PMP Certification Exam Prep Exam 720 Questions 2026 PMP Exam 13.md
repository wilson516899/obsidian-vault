Question 29:

A project manager is developing the project budget and needs to allocate costs across the project timeline to determine funding requirements for each period. The project has detailed cost estimates for all activities, and the sponsor needs to understand when funds will be required throughout the project duration.  
項目經理正在制定項目預算，並需要將各項成本分配到項目的時間段內，以便確定每個階段所需的資金。該項目已經包含了所有活動的詳細成本估算，而贊助方需要了解在項目整個過程中，何時需要資金。

Which budgeting tool should the project manager use?  
項目經理應該使用哪種預算工具？

Your answer is incorrect 您的回答不正確。

Parametric estimating to calculate budget allocations based on historical data  
使用參數估算，根據歷史數據來確定預算分配

Reserve analysis to determine appropriate contingency funding levels  
進行風險分析，以確定合適的備用資金額度

Expert judgment to validate the accuracy of budget distributions  
專家判斷，以驗證預算分配的準確性

Correct answer 正確答案

Cost aggregation to sum costs by time period and create the cost baseline  
通過按時間段彙總成本，並建立成本基準
