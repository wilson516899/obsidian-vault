## ✅ 新增

### git-sync（cron 23:05）
**做了什麼：**
- 建立 `Skills/git-sync/git_sync.sh`
- 每天 23:05 自動 `git add -A → commit → push origin main`
- log 輸出至 `/tmp/git-sync.log`

**推論：**
Vault 有多支腳本每天修改檔案，但沒有自動備份。每天手動 push 容易忘記，造成 GitHub 長期沒有更新。git-sync 讓備份變成零成本的背景任務。

---

### Filesystem MCP
**做了什麼：**
- 安裝 `@modelcontextprotocol/server-filesystem`
- 允許路徑：Vault 根目錄 + `C:/Users/崇瑋/`

**推論：**
Claude Code 原本只能靠工具間接讀寫檔案，MCP 讓我能直接存取 Vault 外的路徑（如 C 槽設定檔），減少繞路操作。

---

### Claude Note 月份系統日誌格式
**做了什麼：**
- 廢除每日自動快照（daily_note.py 23:00 cron 停用）
- 改為月份 Changelog 文件（`YYYY-MM 系統日誌.md`）
- 格式：新增 / 調整 / 刪減 + 每條附推論

**推論：**
每日自動快照只有 checkbox 狀況，跟 Daily Note 內容完全重複，沒有獨立價值。月份日誌記錄系統改動與決策推論，才是跨 session 真正需要的記憶。

## 🔄 調整

### Daily Note 系統大整合（6/7）
**改了什麼：**
- `代辦歷史/` → `Daily Note/`（含月份子資料夾 `Daily Note/2026-05/`）
- `Daily Notes/` → `Claude Note/`
- `今日代辦.md` 停用，功能整合進 `Daily Note/YYYY-MM-DD.md`
- Calendar plugin 指向 `Daily Note/`
- iOS 捷徑（Capture Daily Note）統一寫入 `Daily Note/`
- `Skills/daily-note/` → `Skills/claude-note/`（避免跟 Daily Note 資料夾混淆）

**推論：**
原本三個資料夾（今日代辦 / 代辦歷史 / Daily Notes）功能重疊、命名混亂，連 Calendar 都指錯地方。統一後：Daily Note 是使用者的每日頁面，Claude Note 是 Claude 的系統記憶，兩者定位清楚不互相干擾。

---

### notify.py 記憶來源
**改了什麼：**
- 原本：讀 `Claude Note/` 最近 3 天
- 現在：讀 `Daily Note/` 最近 7 天，只擷取 checkbox 任務完成狀況 + 隨手記（過濾簡報和新聞噪音）

**推論：**
Claude Note 記錄的是我做了什麼，不是使用者實際完成了什麼任務。notify.py 需要的是真實行為資料（勾了什麼、體重幾公斤），讀 Daily Note 才有意義。過濾噪音（每日簡報 / 新聞）是因為那些是已產生的輸出，回讀沒有意義，只浪費 token。

---
