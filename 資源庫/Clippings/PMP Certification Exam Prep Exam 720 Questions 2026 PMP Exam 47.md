Question 164:

A project manager is considering using Monte Carlo analysis to assess project schedule and cost risks. The team wants to understand how this technique works before deciding whether to implement it.  
項目經理正在考慮使用蒙特卡羅分析來評估項目進度和成本風險。團隊希望在決定是否採用這種方法之前，先了解其原理。

Which of the following statements is FALSE about Monte Carlo analysis?  
以下哪句話關於蒙特卡羅分析是錯誤的？

Monte Carlo simulation runs hundreds or thousands of iterations using probabilistic inputs  
蒙特卡羅模擬通過使用概率性輸入，運行數百或數千次迭代。

Correct answer 正確答案

Monte Carlo analysis identifies which individual risk has the greatest impact on the project  
蒙特卡羅分析可以確定哪些個別風險對項目的影響最大。

Monte Carlo simulation produces probability distributions showing likelihood of different outcomes  
蒙特卡洛模擬生成概率分佈，顯示不同結果發生的可能性。

Your answer is incorrect 您的回答不正確。

Monte Carlo analysis uses three-point estimates for activity durations or costs  
蒙特卡羅分析使用三種估計值來估算活動的時長或成本。
