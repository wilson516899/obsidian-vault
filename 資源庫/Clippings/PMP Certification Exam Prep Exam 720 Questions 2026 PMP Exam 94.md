Question 98:問題 98：

A project manager is leading a new initiative to implement a company-wide software system that will improve data handling and reporting. The project team is composed of employees from various departments who have never worked together before. Early in the project, the project manager observes noticeable tension and poor collaboration among team members, which could threaten project success.  
一位專案經理正在領導一項新計畫，實施一套全公司性的軟體系統，以提升資料處理與報告品質。專案團隊由來自不同部門、從未合作過的員工組成。專案初期，專案經理觀察到團隊成員間明顯的緊張與合作不良，可能威脅專案成功。

What should the project manager do to improve teamwork and ensure project success?  
專案經理應該做些什麼來提升團隊合作並確保專案成功？

Correct answer 正確答案

Organize team-building activities that focus on collaboration and communication  
組織以協作與溝通為重點的團隊建立活動

Your answer is incorrect 你的回答不正確

Assign clear roles and responsibilities to each team member in the project plan  
在專案計畫中明確指派每位團隊成員的角色與責任

Implement a conflict resolution protocol to address and resolve disputes quickly  
實施衝突解決程序，以迅速處理並解決爭議

Schedule regular performance reviews to monitor individual contributions to the team  
安排定期績效評估，以監控個人對團隊的貢獻
