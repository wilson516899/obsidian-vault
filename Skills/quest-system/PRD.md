## 一、產品概述

每天完成 OKR 任務 → 累積積分 → 存夠兌換自訂大獎。
進度條每天顯示在今日代辦最上方，讓日常任務與長期目標直接連結。

**設計原則**
- 純加分制，不扣分
- 連擊機制取代懲罰
- 積分門檻對應真實慾望（不是稱號或徽章）
- 獎勵不含食物

---

|------|------|------|------|

| 運動（運動日）| 運動課出席 | +15 pt | 週二四 |
| 社交（每週）| 找團 / 揪人訊息 | +15 pt | 每週一次 |
| 寫作（每週）| 小說或書摘 | +25 pt | 每週一次 |

### 3.2 連擊加成

| 連擊天數 | 每日加成 |
|---------|---------|
| 1–7 天 | +連擊天數 × 2 pt |
| 8 天以上 | 上限 +30 pt / 天 |

> 連擊定義：當天至少完成 1 個任務即維持連擊

## 五、任務格式（checkbox）

今日代辦中任務以 checkbox 呈現，隔天 `quest.py` 讀取昨日歸檔統計：

```markdown
- [x] 記錄體重
- [x] PMP 讀書 45 分鐘
- [x] 飯後走路
- [ ] 無消夜
- [x] 無零食
```

## 六、技術架構

```
Skills/quest-system/
  PRD.md            ← 本文件
  quest.py          ← 主程式：讀昨日歸檔 → 算積分 → 更新進度條
  progress.json     ← 狀態儲存：累計積分、連擊天數、當前目標、里程碑紀錄
```

**執行流程：**
1. `notify.py`（08:00 cron）呼叫 `quest.py`
2. `quest.py` 讀取 `代辦歷史/昨日.md`，統計 `[x]` 任務
3. 計算積分 + 連擊 + 里程碑
4. 更新 `progress.json`
5. 產出進度條區塊，插入 `今日代辦.md` 最上方
