# 大綱

作者定義了人一生所會遇到的四大終極議題。死亡、自由、孤獨以及無意義。
對作者來說，這四者並無先後的重要程度關係，但在我眼中，可以簡化理解為線性的先後順序依循，會比較好去理解此書。並且此書最終印證了存在主義的靈魂語句，Existence precedes essence（存在先於本質）

死亡(人們最終理解自己將死亡，為何卻能正常活著。)

理解死亡焦慮這件事，其本質是害怕我不存在後，沒有人能記得我這件事。存在將不再被證明，意識將消散於空中。這只要是生物，都會本能性的害怕這種狀態，因為其基因無法延續。

而如何逃避死亡。有很多種方法。相信自己是全能的，相信自己會被拯救的。將自己置身於更遠大目標的，這些方法都可以讓你短暫逃離死亡恐懼，但最終你會因為某個劫，而必須回頭去面對它。

從作者的角度，他認為要面對死亡，才有辦法克服死亡。不是指說這樣可以克服死亡本身。而是藉由直面他，來建立正確良好的心態，可以去發展有限的人生，並活出屬於自己的色彩。

自由(有限的生命，抉擇的自由)

當理解生命的局限後，你開始意識到自己的選擇，會為自己的人生給出對等的反饋。因為其有限，你會害怕自己是否做錯。因為其有限，會害怕承擔做錯的後果。然而更深一層探索後，會發現所謂的選擇，並沒有對錯之分。只有你自己如何定義。沒有任何理由貼標，沒有任何藉口去搪塞。這時人們會畏縮，會害怕。那是你自己下的決斷，自己悟出的結論。這些因子，會讓人不想承擔自由，但逃避了自由，就形同逃避了責任。與死亡議題相同，此議題終將回應到自己身上。如果選擇卡在了自ㄧㄡ
