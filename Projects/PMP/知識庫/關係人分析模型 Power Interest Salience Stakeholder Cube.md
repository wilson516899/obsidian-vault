# 關係人分析模型：Power/Interest、Salience、Stakeholder Cube

> [[Projects/PMP/知識庫/_索引|← 知識庫索引]] ｜ `Stakeholders 績效領域` › `Planning` › `Identify Stakeholders`

> [!tip] 一句話核心
> 判斷用哪個模型，**先數題目給了幾個屬性（維度）**。給 **2 個維度** → 二維方格（Power/Interest 或 Power/Influence）；給 **3 個維度**、而且是 **Power／Urgency／Legitimacy** 這組固定的字 → **Salience Model**；給 **3 個維度**但是**空間立體、可視覺化排列**的講法 → **Stakeholder Cube**。

---

## 四種模型，先分類

| 模型                                   | 幾個屬性   | 用的是哪些屬性                                                  | 輸出長相                                                                        |     |
| ------------------------------------ | ------ | -------------------------------------------------------- | --------------------------------------------------------------------------- | --- |
| **Power/Interest Grid**<br>權力／利益方格   | 2      | **Power**（權力）× **Interest**（對專案結果的利益／關心程度）               | 2×2 方格，四象限（高權高利益、高權低利益…）                                                    |     |
| **Power/Influence Grid**<br>權力／影響力方格 | 2      | **Power**（權力）× **Influence**（主動影響專案的能力）                  | 2×2 方格，概念類似 Power/Interest，但 Influence 強調「主動介入、改變結果」的能力，Interest 強調「關不關心結果」 |     |
| **Salience Model**<br>注意力／顯著性模型      | **3**  | **Power**（權力）× **Urgency**（緊迫性）× **Legitimacy**（正當性／合法性） | 三個圓圈交疊的文氏圖，交集越多層代表關係人的「顯著性」越高（如同時具備三者＝Definitive Stakeholder）               |     |
| **Stakeholder Cube**<br>關係人立方體       | 3（可自訂） | 把**任意三個維度**（如 Power/Interest/Attitude）組合成 3D 立方體視覺化      | 立體座標圖，是 Power/Interest 等二維模型的**延伸／進階版**，讓分析可以疊加第三個變數                        |     |

> 🔑 **Salience Model 的三個字是固定組合、有專屬名詞**：Power、Urgency、Legitimacy——這三個詞只要同時出現，答案幾乎鎖定是 Salience Model，不會是別的模型。

---

## 🎯 判準：題目給的屬性組合，直接對應答案

| 題目描述的屬性 | 對應模型 |
|---|---|
| Power（權力）＋ Interest（利益／關心程度） | **Power/Interest Grid** |
| Power（權力）＋ Influence（主動影響力） | **Power/Influence Grid** |
| **Power ＋ Urgency ＋ Legitimacy**（固定三詞） | **Salience Model** |
| 泛稱「三個維度」「立體視覺化」，但**沒有指名 Power/Urgency/Legitimacy** | **Stakeholder Cube** |

本題明確列出「power to influence（權力）、urgency of their claims（緊迫性）、legitimacy of their involvement（合法性）」——**三詞一字不差對上 Salience Model 的定義**，這是送分題等級的關鍵字比對。

---

## 為什麼其他選項錯

| 錯誤選項 | 為什麼錯 |
|---|---|
| Power/Interest Grid | 只有**兩個**屬性（Power、Interest），題目明講**三個**屬性，維度數不對，直接排除 |
| **Power/Influence Grid**（你選的） | 同樣只有**兩個**屬性（Power、Influence），而且屬性名稱裡根本沒有 Urgency 或 Legitimacy，對不上題目描述 |
| Stakeholder Cube | 雖然也是三維，但 Stakeholder Cube **沒有固定使用 Power/Urgency/Legitimacy 這組專屬詞彙**，它是通用的三維視覺化框架，不是這三個詞的專屬模型；題目點名的三詞是 **Salience Model 的招牌屬性** |

> 💡 陷阱模式：四個選項都是「關係人分析模型」家族的真實成員，製造混淆。破解方法很機械化：**先數維度數量（2 個 vs 3 個），再比對關鍵字是否為 Power/Urgency/Legitimacy 這組專屬組合**。
