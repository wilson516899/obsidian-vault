# 莫斯科騾子 Moscow Mule

> 屬於 Free Exploration。  
> 伏特加的 Sparkling 代表，但此杯體驗讓伏特加個性完全消失。

## 酒譜

| 材料 | 份量 |
|------|------|
| 伏特加 (Vodka) | 45 ml |
| 薑汁啤酒 (Ginger Beer) | 120 ml |
| 新鮮萊姆汁 | 15 ml |

- **手法**：Build（直調）
- **杯型**：銅杯 / 雕花銀色金屬杯，大量碎冰，玻璃吸管
- **裝飾**：萊姆角、乾燥柑橘片

## 個人筆記

基本上是薑汁汽水的酒精版。薑味重，幾乎感受不到伏特加的酒精感。  
個人不喜歡薑的刺激感，整體評分極低。

## 延伸探索

> 基於此杯原料，推薦尚未嘗試、但有直接關聯的調酒。

**換基酒 → 同樣薑汁結構，但不同烈酒個性（可跳過薑味問題先）**
- **Kentucky Mule**（波本 + 薑汁啤酒 + 萊姆）— 同結構換波本，威士忌的甜感可能壓住薑味，讓薑變成背景而非主角（Claude推薦）
- **Dark & Stormy**（黑蘭姆 + 薑汁啤酒 + 萊姆）— 黑蘭姆焦糖感更重，與薑的組合是否讓薑更舒服還是更嗆（Claude推薦）

**換掉薑汁啤酒 → 去掉薑，感受伏特加本身**
- **Vodka Gimlet**（伏特加 + 萊姆 + Simple Syrup）— 18杯清單 Sour 項，去掉薑，感受伏特加在酸甜結構裡能不能站出來（Claude推薦）
- **Vodka Martini**（伏特加 + Dry Vermouth）— 18杯清單 Spirit-Forward 項，伏特加在純烈酒型中的表現，幾乎是伏特加的純飲（Claude推薦）

**加苦感 → 伏特加 + 苦感的組合**
- **Espresso Martini**（伏特加 + 濃縮咖啡 + 咖啡利口酒）— 18杯清單 Spirit-Forward 項，咖啡的苦感取代薑的辛感，接近你偏好的苦感方向（Claude推薦）
