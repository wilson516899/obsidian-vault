# Negroni

> **校準基準飲品** ── 甜/酸/苦/酒感/酒體各 3 分，所有評分以此為參照點。

## 個人筆記

心情不好時想喝的酒。  
作為**個人感官校準點**：Campari 的苦 = 4、甜苦艾酒的甜 = 2、酸感極低 = 1、酒精感與口感厚度都高 = 4。  
其他調酒的分數皆相對此杯對應感受來定位，而非固定以「3為中性」計算。

## 延伸探索

> 基於此杯原料，推薦尚未嘗試、但有直接關聯的調酒。

**換基酒 → 同 1:1:1 結構，感受不同烈酒個性**
- **Mezcal Negroni**（Mezcal + Campari + Sweet Vermouth）— 龍舌蘭版，加入煙燻感，適合想探索煙燻維度（Claude推薦）

**換苦味利口酒 → 改變苦感個性**
- **Cynar Negroni**（Gin + Cynar 朝鮮薊苦酒 + Sweet Vermouth）— 把 Campari 換成蔬菜系苦酒，草本感更深、甜感降低（Claude推薦）
- **White Negroni**（Gin + Suze + Lillet Blanc）— 全換成白色系材料，苦感來源截然不同，整體更輕盈（Claude推薦）

**去掉一個材料 → 了解 Campari 獨立的作用**
- **Americano**（Campari + Sweet Vermouth + Soda）— 去掉 Gin，加氣泡水，這是 Negroni 的輕量版，感受沒有基酒時 Campari 本身的表現（Claude推薦）
