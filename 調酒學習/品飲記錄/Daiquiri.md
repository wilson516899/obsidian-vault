# Daiquiri 戴奇麗

## 個人筆記

以酸為主基調，像喝一杯有酒精的綜合水果汁。  
入口酒感明顯，酸性高——但覺得可以**再更酸**。  
適合當第一杯，開胃效果佳。

## 延伸探索

> 基於此杯原料，推薦尚未嘗試、但有直接關聯的調酒。

**加材料 → 在酸甜基礎上增加維度**
- **Hemingway Daiquiri**（白蘭姆 + 萊姆 + 葡萄柚汁 + Maraschino 黑櫻桃利口酒）— 原版 Daiquiri 加葡萄柚苦感與櫻桃香，整體更酸、糖量減半，適合你想要更酸的需求（Claude推薦）
- **Last Word**（琴酒 + Maraschino + Green Chartreuse + 萊姆，四等份）— 萊姆酸 + 草本利口酒，Sour 結構但加入藥草苦感，會接近你喜歡的苦感方向（Claude推薦）

**換基酒 → 同 Sour 結構**
- **Gimlet**（琴酒 + 萊姆 + Simple Syrup）— 把蘭姆酒換成琴酒，感受琴酒植物香氣在 Sour 結構裡的表現（Claude推薦）
- **Margarita**（龍舌蘭 + Triple Sec + 萊姆）— 龍舌蘭版的 Sour，加入橙皮酒，注意橙酒存在感是否干擾（參考 Sidecar 的問題）（Claude推薦）

**變 Spirit-Forward → 蘭姆酒換個方向**
- **El Presidente**（白蘭姆 + Dry Vermouth + 橙皮酒 + 紅石榴糖漿）— 同為蘭姆酒，但走攪拌不搖盪路線，感受蘭姆酒在烈酒型結構的表現（Claude推薦）
