# Lavender Manhattan

> Manhattan 的薰衣草風味變體。此杯作為 18杯清單「威士忌 × Spirit-Forward」的完成項。

## 酒譜（基礎 Manhattan + 薰衣草）

| 材料 | 份量 |
|------|------|
| 波本 / 裸麥威士忌 | 45 ml |
| 甜苦艾酒 (Sweet Vermouth) | 22 ml |
| 苦精 (Angostura Bitters) | 2 dashes |
| 薰衣草糖漿（變體加入）| 適量 |

- **手法**：Stir（攪拌）
- **杯型**：Coupe
- **裝飾**：酒漬櫻桃 或 橙皮
- **背景酒瓶**：Woodford Reserve（波本）、Marie Brizard

## 個人筆記

藥草味重，薰衣草的尾韻明顯。  
威士忌帶出的味道出乎意料——比想像中更溫和，但整體香氣方向不合喜好。  
苦感與酒感都到位，但薰衣草的加入讓整體偏「香水調」。

## 延伸探索

> 基於此杯原料，推薦尚未嘗試、但有直接關聯的調酒。

**去掉薰衣草 → 回到純粹 Manhattan，感受基礎**
- **Manhattan**（Rye Whiskey + Sweet Vermouth + Angostura Bitters）— 同結構不加花香，苦精是 Angostura（丁香 + 肉桂），感受無薰衣草干擾下 Vermouth × 威士忌是什麼樣的苦甜（Claude推薦）
- **Rob Roy**（蘇格蘭威士忌 + Sweet Vermouth + Bitters）— Manhattan 的蘇格蘭版，泥煤煙燻感進入，偏好 Scotch 可從這裡切入（Claude推薦）

**換掉 Vermouth → 同結構換苦味來源**
- **Toronto**（Rye Whiskey + Fernet-Branca + Simple Syrup + Angostura）— 把 Sweet Vermouth 換成 Fernet（更強烈的草本苦酒），苦感大幅提升，接近你喜歡的重苦方向（Claude推薦）
- **Black Manhattan**（Bourbon + Averna Amaro + Bitters）— Vermouth 換成 Averna 草本苦酒，可可 + 草藥尾韻，苦感更厚（Claude推薦）

**加材料 → Manhattan 進階版**
- **Vieux Carré**（Bourbon + Cognac + Sweet Vermouth + Bénédictine + 雙重苦精）— 雙基酒 + 草本利口酒，Spirit-Forward 裡層次最複雜的經典之一（Claude推薦）
