# 修煉積分系統構想

> 靈感來源：系統文套路 × 個人任務激勵
> 狀態：待確認需求後實作

---

## 核心概念

每天完成任務 → 累積積分 → 存夠兌換自訂大獎
進度條直接指向目標，不是空洞的稱號

---

## 每日顯示（插入今日代辦最上方）

```
⚡ 修煉進度  ·  累計：1,240 pt  ·  連擊 7 天 🔥
昨日 +85 pt（4/5 任務完成）

🎯 目標：[大獎名稱]（3,000 pt）
████████████░░░░░░░░  41%  [距目標 1,760 pt]
```

---

## 積分規則

| 任務類型 | 積分 |
|---------|------|
| ① 最重要任務完成 | +30 pt |
| ② 次要任務完成 | +20 pt |
| ③ 其他任務完成 | +10 pt each |
| 小說任務完成 | +25 pt |
| 書摘任務完成 | +15 pt |
| 全部完成加成 | +50 pt |
| 連擊加成 | +連擊天數×2（上限 +30）|

---

## 待確認事項（你需要回答）

**Q1：你的大獎清單是什麼？**
列出 3-5 個你真正想要的東西，我來設定點數門檻。
- 登山裝備？攝影器材？課程報名？某條夢想路線？

**Q2：單目標還是多目標同時顯示？**
- 單目標：進度條專注，就存那一樣
- 多目標：像願望清單，幾樣一起顯示

**Q3：接受任務改成 checkbox 格式嗎？**
→ `- [ ] 任務內容`，你勾完變 `- [x]`，隔天系統才能統計

---

## 技術架構（預計）

```
Skills/quest-system/
  quest.py          # 讀昨天歸檔 → 計算積分 → 更新進度
  progress.json     # 累計積分、連擊天數、當前目標
```

`notify.py` 每天呼叫 `quest.py`，把進度條插到代辦最上方。

---

## 注意事項

- 獎勵不能是食物（減肥中）
- 偏好存夠換大獎，不需要小額即時回饋
- 進度條的視覺感比稱號更重要
