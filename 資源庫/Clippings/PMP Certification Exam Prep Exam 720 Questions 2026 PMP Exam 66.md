Question 41:問題41：

As a project approaches completion, the project manager instructs the team to draft a formal acceptance document for the delivered work.  
當專案接近完成時，專案經理會指示團隊起草一份正式的交付工作驗收文件。

Why is this document crucial for the project manager?  
為什麼這份文件對專案經理至關重要？

Your answer is incorrect 你的回答不正確

It is essential for finalizing all project components as per the project plan  
這是根據專案計畫完成所有專案組成部分的關鍵

It facilitates communication of project completion to all stakeholders  
它促進了向所有利害關係人傳達專案完成的資訊

Correct answer 正確答案

It is necessary for the formal closure of the project or its specific phases  
這是專案或其特定階段正式結束的必要條件

It is required for officially releasing project team members upon completion  
這是專案完成後正式解雇團隊成員的必要條件
