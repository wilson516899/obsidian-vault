# Boulevardier

> **Boulevardier** = Negroni 的威士忌版本，以波本威士忌取代琴酒。  
> 此酒吧版本在 1:1:1 基礎上加重苦精用量（個人俗稱「花花公子」）。  
> 屬於 Free Exploration，非 18杯清單標準項。

## 酒譜

### 📖 標準酒譜（Claude查詢）
| 材料 | 份量 |
|------|------|
| 波本威士忌 (Bourbon) | 45 ml |
| 甜苦艾酒 (Sweet Vermouth) | 30 ml |
| 金巴利 (Campari) | 30 ml |

- **手法**：Stir（攪拌）｜**杯型**：Rocks Glass，大冰塊｜**裝飾**：橙皮扭轉

### ✅ 此杯確認（你的筆記）
- 比例：**1 : 1 : 1**
- 苦精：額外加 **5–6 drops**（高於標準）
- 杯型：水晶 Rocks Glass，單顆大冰塊

## 個人筆記

威士忌香氣盈溢，Vermouth 的苦感比想像中更討喜。  
在 Negroni 1:1:1 基礎上多加 5–6 滴苦精，整體深度明顯提升，苦甜更加平衡。  
**開心時想喝的酒**（對比：Negroni = 心情不好時喝）。

## 延伸探索

> 基於此杯原料，推薦尚未嘗試、但有直接關聯的調酒。

**換掉苦味利口酒 → 感受苦感維度的差異**
- **Black Manhattan**（Bourbon + Averna Amaro + Bitters）— 把 Campari 換成義大利草本苦酒 Averna，苦感更深沉、帶可可與草藥尾韻，接近你偏好的厚重路線（Claude推薦）

**去掉 Vermouth → 還原威士忌 + 苦精的骨架**
- **Old Fashioned**（Bourbon + Sugar Cube + Angostura Bitters）— 去掉 Vermouth，只剩威士忌 × 苦精，感受純基酒 + 苦精的基礎骨幹是什麼感覺（Claude推薦）

**加入酸度 → 同材料變 Sour 結構**
- **Paper Plane**（Bourbon + Aperol + Amaro Nonino + Lemon，四等份）— 把你這杯的苦味方向加入等量酸度與杏仁草本，看苦感 + 酸感能否共存（Claude推薦）

**加複雜度 → Spirit-Forward 進階**
- **Vieux Carré**（Bourbon + Cognac + Sweet Vermouth + Bénédictine + 雙重苦精）— 雙基酒版，加入草本利口酒 Bénédictine，是 Spirit-Forward 裡層次最複雜的經典之一（Claude推薦）
