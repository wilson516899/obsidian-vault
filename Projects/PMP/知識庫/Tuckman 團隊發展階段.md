# Tuckman 團隊發展階段

> [[Projects/PMP/知識庫/_索引|← 知識庫索引]] ｜ `Resources 績效領域` › `Executing` › `Lead the Team`

> [!tip] 一句話核心
> **Tuckman 量的是「團隊互動型態」，不是「個人產出」。**

---

## 五階段

```
Forming → Storming → Norming → Performing → Adjourning
 形成      風暴       規範        表現         解散
```

| 階段                | 團隊狀態      | 辨識關鍵字                   |
| ----------------- | --------- | ----------------------- |
| **Forming** 形成    | 剛認識、客氣、觀望 | 依賴 PM 給方向、角色不清、**尚無衝突** |
| **Storming** 風暴   | 衝突浮現      | 打斷、否定、爭主導權、抗拒協作、有人退縮沉默  |
| **Norming** 規範    | 建立共識      | 開始互信、訂出工作方式、衝突能自行處理     |
| **Performing** 表現 | 自組織       | **相互依賴**、高效交付、PM 可退居支援  |
| **Adjourning** 解散 | 收尾        | 釋出資源、經驗總結、慶祝            |

---

## PM 在各階段的角色（考點）

| 階段           | 領導風格               | 該做什麼           |
| ------------ | ------------------ | -------------- |
| Forming      | **指導型** Directing  | 給方向、訂目標、建立團隊章程 |
| **Storming** | **教練型** Coaching   | 引導衝突浮上檯面並處理    |
| Norming      | **支持型** Supporting | 促進協作、鞏固規範      |
| Performing   | **授權型** Delegating | 退居支援，別擋路       |

---

## ⚠️ 常見陷阱

| 陷阱                                | 破解                                            |
| --------------------------------- | --------------------------------------------- |
| 看到「某人表現優異／高品質產出」就選 **Performing** | 那是**個人**績效。Performing 的定義是**團隊相互依賴**地交付       |
| 團隊在碎裂、各自為政 → 誤判為 Performing       | 方向剛好相反，碎裂是 **Storming**                       |
| 以為「沒人吵架」就是 Norming                | 也可能是 Forming（還在客氣）或 Storming 後期的**壓抑**（有人被消音） |
| 以為階段只能前進                          | **會倒退**。換成員、換範疇、換 PM 都可能打回 Forming/Storming   |

> 💡 一個強力的個人貢獻者，常常是 Storming 的**成因**，不是 Performing 的證據。

---

## 判斷口訣

> **看到「誰厲害」不要選 Performing；看到「大家在吵或在躲」就是 Storming。**
> 看**關係**，不看**績效**。
