# 消費決策系統：什麼時候該貨比三家

> [!abstract] 一句話
> 「貨比三家」不是永遠比價，而是**判斷這筆消費該不該比**。
> 比價的價值 = 節省金額 − 認知成本。在對的地方花注意力。

---

## 一、核心原則

> [!tip] 比價價值公式
> **比價的價值 = 節省金額 − 認知成本**
>
> - 節省 > 成本 → 值得比 → **貨比三家**
> - 成本 > 節省 → 不值得 → **選定生態系、自然累積**

三條底層信念：

1. **時間比點數值錢** — 每年收益 < NT$1,000 又需持續追蹤的活動，預設忽略。
2. **忠誠於價值，不忠誠於平台或點數** — 該比價時不要因為「習慣某平台」而懶得比。
3. **只管理有複利效應的資產** — 注意力留給投資、工作能力、第二大腦、知識複利。

---

## 二、第一層判斷：這筆消費該比價嗎？

這是整套系統的核心概念圖。任何一筆消費先過這道分流：

```
                    一筆消費出現
                         │
              ┌──────────┴──────────┐
              │                     │
       高額 or 低頻？           低額 + 高頻？
   （旅行 / 3C / 家電 /      （日常 / 超商 / 餐飲 /
     大型採購 / 機票飯店）        點數 / 小額消費）
              │                     │
              ▼                     ▼
        ┌─────────┐           ┌──────────┐
        │  比價區  │           │  生態系區 │
        └─────────┘           └──────────┘
     每次貨比三家              選定主力，自然累積
   節省金額 >> 認知成本        認知成本 >> 節省金額
```

> [!note] 為什麼是這條線？
> - **高額低頻**：一次比價省下的金額，遠大於花的時間。值得每次重來。
> - **低額高頻**：天天都在發生，若每次都優化，認知成本會吃掉你的注意力。選一個夠好的生態系，自然累積就好。

---

## 三、比價區（高額・低頻）

> 核心規則：**不要記住哪個平台最便宜，只記住要比三家。**

### 通用比價流程

```
Step 1  找到目標（飯店 / 商品 / 票券）
Step 2  同時開三家平台搜尋
Step 3  比總成本（含早餐？免費取消？預先付款？）
Step 4  選總成本最低方案
Step 5  付款 → 優先 Richart 玩旅刷
```

### 旅行訂房：三家比價

> 台灣使用率：**Agoda > Booking.com > Trip.com**（Expedia / Hotels.com 在台非主流）

| 平台 | 台灣定位 | 最適合的情境 |
|------|---------|------------|
| **Agoda** | 台灣使用率第一、亞洲房源最齊、優惠最多（超級星期三、會員升等 12–25% off、App 專屬價） | 日本、韓國、東南亞首選 |
| **Booking.com** | 第二常用、價格含稅透明、地圖訂房好用、**免費取消最彈性** | 歐美、行程未定要彈性退訂、帶長輩/家庭 |
| **Trip.com** | 一站式（機+酒+交通票券）、中文客服、每月 27 日會員日 | 日本自由行、不想開多視窗比價 |
| Airbnb | 公寓、民宿、長住 | 家庭旅遊、多人分攤 |
| Expedia | 機酒套餐（台灣非主流，需要時才看） | 美國市場 |

> [!tip] 台灣在地比價小技巧
> - 鎖定房型後切換**語系 / 幣別**，常有價差（當地幣別結帳通常省 3–5%）。
> - Agoda、Trip.com 多看 **App 價與會員價**，常比網頁版低。
> - 海外刷卡有 **1.5% 手續費**，退訂通常不退這筆，訂前確認退費政策。
> - 台灣信用卡常有訂房合作（富邦 J 卡、匯豐 Live+、國泰 CUBE 等 5–15% off）；你的主力仍是 **Richart 玩旅刷**，遇到更划算的合作再個案切換。

**各地區預設比價順序：**

| 地區       | 比價順序                       |
| -------- | -------------------------- |
| 日本       | Agoda → Trip.com → Booking |
| 韓國 / 東南亞 | Agoda → Booking            |
| 歐洲       | Booking → Agoda            |
| 美國       | Booking → Expedia          |
| 家庭旅遊     | Airbnb → Booking           |

## 四、生態系區（低額・高頻）

> 核心規則：**選定主力生態系，結帳必報會員，自然累積，不追活動。**

### 信用卡：Richart 為主

```
能用台新 Pay？
│
├─ YES → Pay著刷（3.3%~3.8%，預設模式）
│
└─ NO → 看情境切換權益
         ├─ 出國 / 海外 → 玩旅刷
         ├─ 網購集中月 / AI → 數趣刷
         ├─ 餐廳 → 好饗刷
         ├─ 家電 / 裝潢 / 百貨 → 大筆刷
         └─ 其他 → 天天刷
```

其餘時間一律維持 Pay著刷，不為小回饋頻繁切換。

| 權益模式 | 適用情境 | 回饋 | 適用通路 / 條件 | 狀態 |
|---------|---------|------|----------------|------|
| **Pay著刷** | 預設模式（多數消費）| 3.3–3.8% | 台新 Pay 感應支付 | 已知 |
| **玩旅刷** | 出國 / 海外消費 | \_\_\_\_ | 海外刷卡、旅遊平台 | 待補 |
| **數趣刷** | 網購 / AI 訂閱集中月 | \_\_\_\_ | 網購、數位訂閱（ChatGPT / Claude）| 待補 |

> [!tip] 切換原則（每日可切）
> 權益每天都能換，所以照「當天最大宗消費」切即可，不用綁整月：
> - 出國 / 訂旅遊那天 → 玩旅刷
> - 大額網購 / 續訂 AI 那天 → 數趣刷
> - 上餐廳那天 → 好饗刷
> - 買家電百貨那天 → 大筆刷
> - 其餘日常 → 維持 Pay著刷
>
> 原則不變：不為小回饋每天糾結，只在「當天有明確大宗消費」時才切。權益有效期至 **2027/03**。

- **交通**：TPASS 1200（Garmin 悠遊卡），效益遠高於信用卡交通回饋，不為回饋改變交通工具。

## 五、優先級矩陣

注意力分配的總表——決定每件事「投入多少管理成本」：

| Tier | 處理方式 | 項目 |
|------|---------|------|
| **S** | 重點管理 | ETF、股票、資產配置、第二大腦、工作能力 |
| **A** | 定期檢視 | Richart 權益、OPENPOINT 生態 |
| **B** | 自然累積 | Fa 點、誠品會員 |
| **C** | 忽略 | 單次優惠、集點活動、小額折價券、限時活動 |

> [!important] 新優惠的判斷規則
> 當發現新的優惠時，問自己一句：
> **「這件事能提升到 A 級以上嗎？」**
> 不能 → 直接忽略。

## 六、總結

> [!summary]
> 消費系統的目標**不是取得極限回饋**，而是用最低管理成本拿到大部分價值。
>
> - **高額低頻** → 貨比三家（旅行、活動、大型採購）
> - **低額高頻** → 選定生態系、自然累積（信用卡、超商、點數）
>
> 比價一次省下的金額，通常遠大於信用卡回饋 + 點數活動 + 會員福利的總和。
> 而省下的注意力，要投資在報酬率更高的地方：**投資、能力成長、知識複利、第二大腦。**
