## ✅ 新增

### git-sync（cron 23:05）
**做了什麼：**
- 建立 `Skills/git-sync/git_sync.sh`
- 每天 23:05 自動 `git add -A → commit → push origin main`
- log 輸出至 `/tmp/git-sync.log`

**推論：**
Vault 有多支腳本每天修改檔案，但沒有自動備份。每天手動 push 容易忘記，造成 GitHub 長期沒有更新。git-sync 讓備份變成零成本的背景任務。

### quest.py NameError（啟動即崩潰）
**修了什麼：**
- `AGENDA_PATH` 第 17 行用了 `YESTERDAY`，但 `YESTERDAY` 到第 21 行才定義

**推論：**

### extract_daily_note_summary() 抓到簡報噪音
**修了什麼：**
- 正則 `(?=\n## |\n---\n##|\Z)` 無法在 `## 每日簡報` 前停止（實際格式是 `\n---\n\n##`，雙換行）
- match 跑到 `## 隨手記` 才停，把整個每日簡報都帶進 notify.py 的上下文
- 修為 `(?=\n---|\n## |\Z)`，遇到任何 `---` 分隔線即停

**推論：**
這讓 notify.py 讀過去 7 天時把舊新聞帶回來，形成回音並浪費 token。根本原因是模板有額外換行，但正則沒有對應。
