## 台灣去中國的限制

| 項目 | 說明 |
|------|------|
| **入境証件** | 需持**台胞証**（台灣居民來往大陸通行證），不是護照 |
| **申辦** | 建議出發前 1–2 個月辦理，首次需本人親到 |
| **直航** | 重慶・成都・廈門等有直航；班次比疫情前少 |
| **張家界** | 無直飛，需從長沙轉 |
| **西藏** | 額外需西藏旅遊許可証＋強制參加指定旅行社 |
| ⚠️ | 兩岸政治影響政策，出發前1個月再確認陸委會公告 |
