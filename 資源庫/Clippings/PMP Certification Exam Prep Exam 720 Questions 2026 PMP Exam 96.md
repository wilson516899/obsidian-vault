Question 99:問題 99：

A project manager is overseeing a large construction project involving multiple subcontractors and a diverse crew. Recently, there have been several incidents of miscommunication leading to delays and increased costs. The project manager recognizes a need for better coordination and communication among all parties involved.  
一位專案經理正在監督一個涉及多家分包商和多元團隊的大型施工專案。近期發生多起溝通不良事件，導致延誤與成本增加。專案經理意識到所有相關方之間需要更好的協調與溝通。

What should the project manager do to improve coordination and reduce misunderstandings?  
專案經理應該如何改善協調並減少誤解？

Correct answer 正確答案

Introduce mandatory weekly coordination meetings with all subcontractors and key team members  
引入強制性的每週協調會議，與所有分包商及關鍵團隊成員

Your answer is incorrect 你的回答不正確

Develop a centralized, real-time communication dashboard to keep all parties updated simultaneously  
建立集中式、即時溝通儀表板，讓所有相關方同時掌握最新狀況

Enforce a policy where all communication must go through a designated project communication officer  
執行一項政策，要求所有溝通必須由指定的專案溝通官完成

Create a detailed communication flowchart that specifies the channels and protocols for sharing information  
建立詳細的溝通流程圖，明確說明資訊分享的管道與規範
