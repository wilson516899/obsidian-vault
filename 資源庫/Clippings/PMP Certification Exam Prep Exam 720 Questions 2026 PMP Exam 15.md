Question 32:

A project manager is in the early planning stages of a construction project and needs to provide a preliminary cost estimate to determine if the project is financially viable. Detailed specifications and designs have not yet been developed, but the organization needs a rough order of magnitude estimate to decide whether to proceed with detailed planning.  
項目經理正處於一個建築項目的初期規劃階段，需要提供一個初步的成本估算，以便評估該項目是否具有經濟可行性。雖然尚未制定詳細的規格和設計，但組織需要一個大致的成本範圍，以便決定是否繼續進行詳細的規劃。

Which cost estimating technique should the project manager use?  
項目經理應該使用哪種估算方法？

Bottom-up estimating by analyzing costs for each detailed work package  
通過分析每個具體工作包的各項成本，進行從“底層”到“頂層”的估算。

Your answer is incorrect 您的回答不正確。

Three-point estimating using optimistic, pessimistic, and most likely scenarios  
使用樂觀、悲觀和最可能情景的三個點估計

Definitive estimating based on comprehensive resource and activity analysis  
基於全面資源和活動分析的精確估算

Correct answer 正確答案

Analogous estimating using historical data from similar construction projects  
通過類似建設項目的歷史數據，進行估算
