Question 81:問題81：

In an effort to optimize the release process for a new mobile application, the project manager is evaluating strategies to ensure higher quality and faster deployment times.  
為了優化新行動應用程式的發佈流程，專案經理正在評估策略，以確保更高品質與更快的部署時間。

What strategy should the project manager recommend to achieve these objectives?  
專案經理應該建議什麼策略來達成這些目標？

Correct answer 正確答案

Implement automated regression testing within the CI/CD pipeline for immediate feedback on code changes  
在 CI/CD 流程中實施自動回歸測試，以便即時獲得程式碼變更的回饋

Introduce a peer review process before each merge to the main codebase to catch issues early  
在每次合併前引入同儕審查流程，讓主程式碼庫能及早發現問題

Schedule regular code audits with external consultants to ensure adherence to best practices  
定期與外部顧問進行程式碼稽核，以確保遵循最佳實務
